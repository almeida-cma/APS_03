📄 form1.py - Lógica do Jogo 
import random  # Necessário para a IA escolher aleatoriamente

class Form1(Form1Template):
  
  def __init__(self, **properties):
    # Inicializa o form e os componentes do Anvil
    self.init_components(**properties)

    # =========================
    # VARIÁVEIS DE ESTADO (MEMÓRIA)
    # Guarda a pontuação enquanto a tela estiver aberta
    # =========================
    self.pontos_jogador = 0
    self.pontos_cpu = 0


  # =========================
  # EVENTOS DE CLIQUE DOS BOTÕES
  # Capturam o botão clicado e repassam para a lógica
  # =========================
  def button_pedra_click(self, **event_args):
    self.jogar("Pedra")

  def button_papel_click(self, **event_args):
    self.jogar("Papel")

  def button_tesoura_click(self, **event_args):
    self.jogar("Tesoura")


  # =========================
  # MOTOR DO JOGO (LÓGICA PRINCIPAL)
  # =========================
  def jogar(self, escolha_jogador):
    
    # 1. CPU escolhe aleatoriamente
    opcoes = ["Pedra", "Papel", "Tesoura"]
    escolha_cpu = random.choice(opcoes)
    
    # Mostra na tela o que a CPU escolheu
    self.label_escolha_cpu.text = f"🤖 CPU escolheu: {escolha_cpu}"

    # 2. Verifica a Regra de Negócio (Quem Ganhou?)
    if escolha_jogador == escolha_cpu:
      resultado = "EMPATE! 😐"
      cor = "#f39c12"  # Laranja

    elif (escolha_jogador == "Pedra" and escolha_cpu == "Tesoura") or \
         (escolha_jogador == "Papel" and escolha_cpu == "Pedra") or \
         (escolha_jogador == "Tesoura" and escolha_cpu == "Papel"):
      resultado = "VOCÊ VENCEU! 🎉"
      cor = "#27ae60"  # Verde
      self.pontos_jogador += 1  # Adiciona ponto ao jogador

    else:
      resultado = "VOCÊ PERDEU! 😢"
      cor = "#e74c3c"  # Vermelho
      self.pontos_cpu += 1      # Adiciona ponto à CPU

    # 3. Atualiza a Tela (Saída de Dados)
    self.label_resultado.text = resultado
    self.label_resultado.foreground = cor
    
    # Atualiza o texto do placar com os novos pontos
    self.label_placar.text = f"👤 Jogador: {self.pontos_jogador} | 🤖 CPU: {self.pontos_cpu}"
📖 ETAPA 8 — EXPLICAÇÃO DETALHADA DO CÓDIGO Entenda a mágica por trás do jogo

📦 IMPORTANDO MÓDULOS

No Python, import random traz uma "caixa de ferramentas" pronta para lidar com aleatoriedade. Sem ela, a CPU não saberia como escolher itens de forma imprevisível.

🧠 VARIÁVEIS DE ESTADO

Criamos self.pontos_jogador = 0 dentro do bloco __init__. O Anvil roda o Init ao abrir a página. Ao usar o self., garantimos que a variável não seja apagada entre as rodadas do jogo.

🔀 FUNÇÕES AUXILIARES

Em vez de escrever a regra do jogo três vezes (uma para cada botão), criamos uma função extra jogar(escolha). Os botões apenas enviam a "arma" selecionada para esta função principal trabalhar.

🎲 A JOGADA DA CPU

O comando random.choice(opcoes) pega a lista que criamos (Pedra, Papel, Tesoura) e seleciona um item aleatório, exatamente como o cérebro da CPU.

⚔️ MATRIZ DE VITÓRIA

A estrutura de if / elif / else verifica: 1º Se for igual = Empate. 2º Colocamos TODAS as 3 regras de vitória dentro de parênteses separadas por or (Ou). 3º Qualquer outra coisa que sobrar no Else, significa Derrota.

🔢 INCREMENTO MATEMÁTICO

O operador += 1 (Ex: self.pontos_cpu += 1) é o mesmo que dizer "pegue o valor atual e some + 1 a ele". Essencial para criar placares que crescem progressivamente.

Os principais insights desta construção

✅ Sortear itens em uma lista Python (random.choice).
✅ Usar operadores lógicos (and / or / \) em regras complexas.
✅ Incrementar números (+= 1) para gerar contadores e placares.
