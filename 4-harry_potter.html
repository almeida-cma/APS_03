📄 form1.py 
from anvil import alert  # Importação necessária para o Pop-up

class Form1(Form1Template):
  
  def __init__(self, **properties):
    self.init_components(**properties)

  def button_revelar_click(self, **event_args):
    
    # =========================
    # 1. VALIDAÇÃO DE SEGURANÇA
    # Garante que uma opção de cada grupo foi marcada
    # (.selected retorna True se marcado, False se não)
    # =========================
    
    respondeu_q1 = self.rb_1a.selected or self.rb_1b.selected or self.rb_1c.selected or self.rb_1d.selected
    respondeu_q2 = self.rb_2a.selected or self.rb_2b.selected or self.rb_2c.selected or self.rb_2d.selected
    respondeu_q3 = self.rb_3a.selected or self.rb_3b.selected or self.rb_3c.selected or self.rb_3d.selected
    
    if not (respondeu_q1 and respondeu_q2 and respondeu_q3):
        alert("⚠️ Por favor, responda todas as perguntas do Quiz!", title="Atenção")
        return  # Interrompe o cálculo

    # =========================
    # 2. DICIONÁRIO DE PONTUAÇÃO
    # Todos começam com ZERO pontos
    # =========================
    
    pontos = {
        "⚡ Harry Potter": 0,
        "📚 Hermione Granger": 0,
        "🍗 Ron Weasley": 0,
        "🐍 Draco Malfoy": 0
    }

    # =========================
    # 3. DISTRIBUIÇÃO DOS PONTOS
    # Lendo as respostas e somando no Dicionário
    # =========================
    
    # Pergunta 1
    if self.rb_1a.selected: pontos["⚡ Harry Potter"] += 1
    elif self.rb_1b.selected: pontos["📚 Hermione Granger"] += 1
    elif self.rb_1c.selected: pontos["🍗 Ron Weasley"] += 1
    elif self.rb_1d.selected: pontos["🐍 Draco Malfoy"] += 1

    # Pergunta 2
    if self.rb_2a.selected: pontos["⚡ Harry Potter"] += 1
    elif self.rb_2b.selected: pontos["📚 Hermione Granger"] += 1
    elif self.rb_2c.selected: pontos["🍗 Ron Weasley"] += 1
    elif self.rb_2d.selected: pontos["🐍 Draco Malfoy"] += 1

    # Pergunta 3
    if self.rb_3a.selected: pontos["⚡ Harry Potter"] += 1
    elif self.rb_3b.selected: pontos["📚 Hermione Granger"] += 1
    elif self.rb_3c.selected: pontos["🍗 Ron Weasley"] += 1
    elif self.rb_3d.selected: pontos["🐍 Draco Malfoy"] += 1

    # =========================
    # 4. DESCOBRINDO O VENCEDOR E EXIBINDO
    # Função MAX procura a chave com o maior valor no Dicionário
    # =========================
    
    personagem_vencedor = max(pontos, key=pontos.get)
    
    mensagem = f"O Chapéu Seletor analisou suas respostas!\n\nSua personalidade bate com:\n{personagem_vencedor}"
    
    # Dispara o Pop-up Final!
    alert(mensagem, title="🔮 RESULTADO DO QUIZ", large=True)
📖 ETAPA 8 — EXPLICAÇÃO DETALHADA DO CÓDIGO Entenda a lógica de um Quiz

🔘 .selected (Verdadeiro ou Falso)

O TextBox possui a propriedade .text. Já o RadioButton possui a .selected. Se ele estiver marcado, o Python lê como True. Senão, False.

🛡️ Lógica do "OR" (Ou) na Validação

if a ou b ou c ou d: - Isso significa: "Se PELO MENOS UM deles for True, a pergunta foi respondida". Se nenhum for True, o if not final trava a execução.

📚 DICIONÁRIOS (Chave: Valor)

O pontos = {"Harry": 0} é um Dicionário. É uma das estruturas mais poderosas do Python! Criamos "Gavetas" com o nome do personagem, e guardamos o número "0" dentro delas.

➕ SOMA NO DICIONÁRIO

Para somar pontos, acessamos a gaveta pelo nome dela e usamos o operador de incremento: pontos["Harry"] += 1.

🥇 A FUNÇÃO max()

A mágica acontece em: max(pontos, key=pontos.get). Isso diz ao Python: "Olhe todas as gavetas dentro do Dicionário, descubra qual tem o maior número dentro, e me devolva a CHAVE (o nome) dessa gaveta."

📝 Quebra de Linha em F-Strings

Na mensagem do alert, usamos \n. No Python, isso significa "Enter" (Pular linha). Isso deixa o texto do Pop-up muito mais organizado e bonito.
