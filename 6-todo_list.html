✅ ETAPA 1 — REQUISITOS FUNCIONAIS O Motor do CRUD

➕ CREATE & READ

O usuário deve poder digitar uma Tarefa e um Link opcional. A tarefa deve aparecer em uma lista visual imediatamente.

🔄 UPDATE

Cada tarefa deve possuir uma caixa de seleção (Checkbox). Ao marcá-la, a tarefa muda para o status de "Concluída".

🗑️ DELETE

O usuário deve ser capaz de remover tarefas específicas da lista permanentemente através de um botão de exclusão.

💾 EXPORT & IMPORT

Como os dados ficam em memória RAM temporária, o app deve permitir baixar a lista como arquivo `.json` e carregá-la de volta depois.

💻 ETAPA 7 — CÓDIGO PYTHON COMPLETO Construção de UI Dinâmica e JSON - Copie e Cole
📄 form1.py 
from anvil import *
import anvil.media
import json
import time  # Para gerar IDs únicos

class Form1(Form1Template):
  
  def __init__(self, **properties):
    self.init_components(**properties)
    
    # Memória Temporária (Simulando LocalStorage/Database)
    self.tarefas = []
    
    # Renderiza a tela limpa inicial
    self.renderizar_lista()

  # ==========================================
  # C R U D - CREATE (Adicionar)
  # ==========================================
  def btn_adicionar_click(self, **event_args):
    descricao = self.txt_descricao.text
    link = self.txt_link.text
    
    # Validação contra tarefas vazias
    if not descricao:
      return
      
    # Criação do Dicionário da Tarefa
    nova_tarefa = {
      "id": int(time.time() * 1000), # ID único baseado no relógio
      "descricao": descricao,
      "link": link,
      "feita": False
    }
    
    # Adiciona na memória
    self.tarefas.append(nova_tarefa)
    
    # Limpa os campos de texto
    self.txt_descricao.text = ""
    self.txt_link.text = ""
    
    # Recria a tela
    self.renderizar_lista()

  # ==========================================
  # C R U D - READ (Montar a Lista Visual)
  # ==========================================
  def renderizar_lista(self):
    self.painel_tarefas.clear()
    
    for t in self.tarefas:
      # Cria uma "Linha" horizontal para a tarefa
      linha = FlowPanel(align="justify")
      
      # 1. Checkbox de Conclusão
      chk = CheckBox(text=t["descricao"], checked=t["feita"])
      chk.tag = t["id"]  # Guarda o ID para saber qual alterar
      chk.set_event_handler('change', self.alterar_status)
      
      # Efeito visual de riscado
      if t["feita"]:
        chk.foreground = "#9ca3af"  # Cinza
        
      linha.add_component(chk)
      
      # 2. Link opcional
      if t["link"]:
        lnk = Link(text="🔗 Link", url=t["link"])
        linha.add_component(lnk)
        
      # 3. Botão de Deletar
      btn_del = Button(text="❌", role="primary-color", foreground="#ef4444")
      btn_del.tag = t["id"] # Guarda o ID para deletar o certo
      btn_del.set_event_handler('click', self.deletar_tarefa)
      linha.add_component(btn_del)
      
      # Adiciona a linha pronta no painel principal da tela
      self.painel_tarefas.add_component(linha)


  # ==========================================
  # C R U D - UPDATE (Alterar Status)
  # ==========================================
  def alterar_status(self, sender, **event_args):
    id_alvo = sender.tag
    
    # Busca a tarefa na lista e inverte o status
    for t in self.tarefas:
      if t["id"] == id_alvo:
        t["feita"] = sender.checked
        break
        
    self.renderizar_lista()

  # ==========================================
  # C R U D - DELETE (Remover)
  # ==========================================
  def deletar_tarefa(self, sender, **event_args):
    id_alvo = sender.tag
    
    # Recria a lista de tarefas IGNORANDO a que tem o ID clicado
    self.tarefas = [t for t in self.tarefas if t["id"] != id_alvo]
    
    self.renderizar_lista()


  # ==========================================
  # JSON - EXPORTAR (Baixar)
  # ==========================================
  def btn_exportar_click(self, **event_args):
    # Converte a Lista de Dicionários Python para texto JSON
    json_texto = json.dumps(self.tarefas, indent=4)
    
    # Transforma o texto em um Arquivo (BlobMedia)
    arquivo = anvil.BlobMedia('application/json', json_texto.encode(), name='minhas_tarefas.json')
    
    # Inicia o download no navegador do usuário
    anvil.media.download(arquivo)


  # ==========================================
  # JSON - IMPORTAR (Upload FileLoader)
  # ==========================================
  def fl_importar_change(self, file, **event_args):
    # Lê os bytes do arquivo e converte para texto normal (utf-8)
    conteudo_texto = file.get_bytes().decode('utf-8')
    
    try:
      # Transforma o texto JSON de volta para Lista de Dicionários Python
      self.tarefas = json.loads(conteudo_texto)
      self.renderizar_lista()
    except Exception as e:
      alert("Arquivo JSON inválido ou corrompido!")
📖 ETAPA 8 — EXPLICAÇÃO DETALHADA DO CÓDIGO Os segredos do código dinâmico

🧱 FlowPanel vs LinearPanel

Na Etapa anterior usamos LinearPanel (coloca coisas uma embaixo da outra). Aqui, para a tarefa, criamos um FlowPanel via código. Ele enfileira componentes um ao lado do outro (Checkbox -> Link -> Lixeira), montando nossa "linha da tabela".

🔗 A Mágica do .tag e do ID

Como criamos dezenas de tarefas, como saber qual deletar? Geramos um ID usando o relógio time.time(). Guardamos esse ID na propriedade .tag do Botão de Excluir. Quando ocorre o clique, lemos o tag e achamos a tarefa na lista!

🧹 O padrão Delete em Python

No deletar_tarefa, nós usamos *List Comprehension*. Dizemos: "A nova lista de tarefas é igual a antiga, MAS SÓ COPIE as tarefas cujo ID seja diferente do que eu cliquei." Isso extingue a tarefa velha!

📤 json.dumps() e BlobMedia

json.dumps() "Despeja" (dumps) código Python virando texto puro em formato JSON. O BlobMedia é a forma do Anvil empacotar esse texto e avisar ao navegador: "Isso é um arquivo .json, chame o download!".

📥 json.loads() e FileLoader

O FileLoader é maravilhoso. Ele captura arquivos do PC. Com file.get_bytes() lemos o arquivo criptografado, decodificamos para texto, e o json.loads() "Carrega" (loads) o texto transformando-o novamente em uma Lista Python!
